ᚲ Parallely

Ship features in parallel, not in sequence.

Split a large task into sections and run one AI coding agent per section concurrently — each in a shared git worktree, supervised from a live terminal UI, auto-committed to one integration branch.

View on GitHub Install
parallely · run

A real run — three sections built concurrently by Claude Code agents, then consolidated onto one integration branch.

How it works

01

Plan

Define — or AI-generate — parallel sections, each with its own scope and acceptance criteria.

02

Execute

One agent per section launches concurrently in a shared git worktree.

03

Monitor

A fullscreen TUI streams real-time progress, output, and token usage for every agent.

04

Merge

Section work is auto-committed and consolidated onto one integration branch.

Install

$ git clone https://github.com/MichaelTheMay/parallely.git
$ cd parallely
$ bun install
$ bun run build && bun install -g .
$ parallely --help

Requires Bun 1.0+ and at least one agent CLI (codex, claude, or opencode).
